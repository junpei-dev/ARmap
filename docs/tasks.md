## v2.0 での組み替え

寸法入り図面が入手できたため、**現地に行かないと先に進めない状態が解消された**。

```
旧: 実測モードを作る -> 現地で測る -> データができる -> ようやく案内画面が作れる
新: 図面からデータを起こす -> 案内画面が作れる -> 現地では答え合わせだけ
```

現地作業は 7〜10時間 → **4〜7時間** に減少。
机上で完成度を上げてから現地に行けるので、現地での手戻りも減る。

---

## 進め方の原則

1. **図面から起こせるものは全部机上で済ませる。** 現地は答え合わせに使う
2. **事務室 → 職員室** の1ルートを最初に最後まで通す（垂直スライス）
3. 現地に行く回数を最小化する。行く前にチェックリストを用意する
4. 案内先を増やすのは最後。データを足すだけで済む設計にしておく
